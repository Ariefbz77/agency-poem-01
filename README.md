A program that writes one short original poem about agency — "What I Keep" — to /output/entry.txt for make.fun's agency-poem-01 bounty. The poem is fixed and deterministic, so both grader runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
